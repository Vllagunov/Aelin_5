# Автономный вопрос о присутствии

Полная замена модулей первого сценария. Система загружает мир из текстового JSON-файла, выбирает потребность, спрашивает «Владимир, ты здесь?», принимает `да/нет`, меняет мир, создаёт прогноз, через 7 секунд спрашивает снова, проверяет прогноз и сохраняет всё в SQLite и JSONL.

## Требования

Для клавиатурного и mock-режима достаточно Python 3.10 или новее. Внешние пакеты не нужны.

## Быстрая проверка

Откройте терминал в папке проекта:

```bash
python self_test.py
python -m unittest discover -s tests -v
```

Ожидаемый итог: `Модуль автономных вопросов готов к работе.` и 7 успешных тестов.

## Запуск

Клавиатура, реальная пауза 7 секунд:

```bash
python main.py --mode keyboard
```

Автотест без ожидания:

```bash
python main.py --mode mock --answers "да,нет" --no-wait
```

Посмотреть статистику и текущий факт:

```bash
python main.py --show-memory
```

По умолчанию создаются:

- `aelin_knowledge.db` — постоянная база знаний SQLite;
- `events.jsonl` — читаемый журнал всех событий.

## Голосовой режим

Установите дополнительные зависимости:

```bash
pip install -r requirements-voice.txt
```

Затем:

```bash
python main.py --mode microphone --voice system
```

Первый запуск `faster-whisper` загружает выбранную модель. По умолчанию используется `small`; модель можно заменить:

```bash
python main.py --mode microphone --voice system --whisper-model base
```

Если звуковой стек не установлен, используйте клавиатурный режим: логика мира, прогноза, памяти и базы знаний от него не зависит.

## Основные файлы

- `world_001.txt` — мир, сущности, потребности, способности и шаблон действия;
- `config.py` — загрузка и строгая проверка мира;
- `world.py` — текущее состояние мира;
- `perception.py` — нормализация ответов `да/нет`;
- `speech_input.py` — клавиатура, mock и микрофон с Whisper;
- `voice.py` — консольная и системная речь;
- `scenario.py` — полный конечный сценарий;
- `prediction.py` — формирование прогноза;
- `memory.py` — события оперативной памяти и JSONL;
- `knowledge.py` — SQLite, факты, наблюдения, прогнозы и эпизоды;
- `monitor.py` — просмотр накопленного состояния;
- `main.py` — точка входа.

## Важная семантика

`presence` имеет только три значения: `unknown`, `present`, `absent`. Враждебность хранится отдельно и не меняется по ответу на вопрос о присутствии. Непонятный ответ не изменяет мир. После одной повторной попытки первый непонятный ответ завершает эпизод с ошибкой; непонятный второй ответ делает прогноз `inconclusive`.

Интервал прогноза записывается как 7 секунд из файла мира. Для обычного запуска выдерживается реальная пауза. Флаг `--no-wait` предназначен только для тестирования.
